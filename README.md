# CurseForge Mod Tool (personal)

A personal, local-only tool that searches and downloads Minecraft mods
using the CurseForge 3rd-party API.

## Features
- Search mods by game version / loader / category
- Resolve dependencies and download mod files into a local mods/ folder

## API compliance
- The API key is stored locally and is never shared or committed.
- No API data is persisted or cached; responses are used in memory only.
- Requests go directly to the CurseForge API (no proxy/VPN).
- This is a personal tool, not a competing product or public service.
